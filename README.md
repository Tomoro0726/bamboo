# bamboo

無意味に文章を伸ばす。竹は中身がからっぽであるため、`bamboo` 。

```bash
gh skill install tomoro0726/bamboo bamboo
```

## 動作例

### 例 1

**入力:**
> お昼ごはん何にしましょうか？

**出力:**
> 限られたランチタイムというスコープの中で午後のパフォーマンスを最大化するという観点において、どのようなフード・ソリューションをチョイスすべきか、お互いのニーズとコンテキストをアラインさせながらクイックにコンセンサスを形成していきたいところですが、いかがアセスメントされますか？

### 例 2

**入力:**
> 眠いのでもう寝ます。

**出力:**
> 現状のバイタル・アセットに明確なボトルネックが生じているというファクトを踏まえつつ、ここはいったん現在のオペレーションをクローズし、スリープという最もROIの高いリカバリー・プロセスへとフェーズを移行させていただく所存です。

### 例 3

**入力:**
> この資料、明日までに確認をお願いします。

**出力:**
> 本件のアジェンダを進めるにあたり、共有させていただいたマテリアルについて、明日のタイムラインをデッドラインという前提のもとで内容の整合性やイシューの有無をアセスメントしていただき、フィードバックをアラインさせていただけますと幸いです。

### 例 4

**入力:**
> すみません、今日は忙しいので行けません。

**出力:**
> 大変恐縮ではございますが、本日のリソース・アロケーションにおいてキャパシティのボトルネックが発生しているというコンテキストを踏まえ、当該セッションへのジョインについては今回はスコープ外としてハンドリングさせていただきたく存じます。
